QUICK INSTALL (5 MINUTES)
==========================================

1. LOG INTO CPANEL
   - Go to your hosting control panel
   - Open File Manager

2. UPLOAD THIS ZIP
   - Navigate to public_html
   - Click "Upload"
   - Select this ZIP file
   - Wait for upload to complete

3. EXTRACT FILES
   - Right-click the ZIP file
   - Select "Extract"
   - Extract to public_html
   - Delete the ZIP file after extraction

4. RUN SETUP
   - Open browser
   - Visit: https://yourdomain.com/setup.php
   - Click "Initialize Data Storage"
   - Wait for success message

5. SECURE YOUR INSTALL
   - Delete setup.php (for security)
   - Done!

==========================================
TROUBLESHOOTING
==========================================

If setup.php shows errors:

1. Check PHP version (must be 7.4+)
   - cPanel → Select PHP Version

2. Check file permissions
   - Folders: 755
   - Files: 644

3. Make sure data/ directory is writable
   - Right-click → Change Permissions → 755
